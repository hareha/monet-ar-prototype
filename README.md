# 모네 "살아나는 그림" AR 프로토타입

벽에 걸린 그림에 폰 카메라를 비추면, 그림 위에 영상이 정합되어 재생되는 WebAR 프로토타입.
앱 설치 없음 — 브라우저에서 바로 실행.

## 사용법
1. **폰**에서 `index.html` 열기 → 시작 → 타깃 분석(10~30초) → 카메라 허용
2. **다른 화면**(노트북/모니터)에 `wall.html`을 띄워 벽의 그림 대용으로 사용 (또는 target.jpg 출력물)
3. 폰으로 그림을 비추면 원화가 숨쉬듯 움직이는 영상이 그림 위에 붙어 재생

## 구성
- `target.jpg` — 타깃: Claude Monet, *Woman with a Parasol* (1875) · 퍼블릭 도메인 (Wikimedia Commons)
- `living.mp4` — 원화 첫 프레임에서 시작하는 10초 루프 (ffmpeg zoompan+hue로 생성)
- `index.html` — AR 뷰어 · [MindAR](https://github.com/hiukim/mind-ar-js) (MIT) + three.js · 타깃은 접속 시 브라우저에서 즉석 컴파일
- `wall.html` — 타깃 그림 전체화면 (2번째 기기용)

## 기술 메모
- 이미지 트래킹: 그림 내부 특징점 기반 (액자·외곽 형태 아님)
- 영상 평면은 타깃 대비 2% 오버스케일 — 경계 미세 오차 커버
- 첫 프레임 = 원화와 동일 → "그림이 살아나는" 체감, 경계 인지 안 됨
- 운영 배포 시엔 즉석 컴파일 대신 사전 컴파일된 `.mind` 파일 사용 권장 (로딩 즉시화)
